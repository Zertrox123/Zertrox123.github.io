### Overview

Personal portfolio web application showcasing low-level systems, concurrent architectures, network protocols, and artificial intelligence projects.

- **Live URL:** [https://zertrox123.github.io](https://zertrox123.github.io)
- **Backend Architecture:** Rust, Rocket, Tera Template Engine
- **Frontend Stack:** HTML5, CSS3 (Custom Responsive Dark Theme, Dynamic Ticker, Crazy Mode)

### Local Development

To run the Rust Rocket server locally:

```bash
# Clone the repository
git clone git@github.com:Zertrox123/Zertrox123.github.io.git
cd Zertrox123.github.io

# Launch Rocket web server
cargo run
```

The application will be accessible locally at `http://localhost:8000`.
