2024-2025 Mathematiques Appliquees

Description du projet

Serie de projets mathematiques en Python (B-MAT-100 / B-MAT-200). Chaque projet applique un concept mathematique a un probleme concret : - 101pong : Calcul de vecteur vitesse et prediction de trajectoire 3D - 102architect : Multiplication de matrices pour les transformations geometriques (rotation, translation, scaling) - 103cipher : Chiffrement de Hill par multiplication matricielle - 104neutrinos : Calcul de statistiques en continu (moyenne, ecart-type, quadratique) sans stocker les valeurs - 105demography : Regression par moindres carres pour des courbes de croissance demographique La contrainte c'est de tout coder from scratch sans bibliotheques math externes.

Technologies utilisees

Python Linear Algebra Statistics Cryptography
