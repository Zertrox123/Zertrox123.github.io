Secured

2024 Structures de Donnees

Description du projet

Implementation d'une table de hachage en C (B-CPE-110). Le programme stocke des paires cle-valeur avec une fonction de hash custom. Gestion des collisions par chainage (listes chainees dans chaque bucket), avec operations d'insertion, recherche et suppression en temps moyen constant. Ca apprend a comprendre comment fonctionnent les dictionnaires et les maps sous le capot.

Technologies utilisees

C Hash Table Linked Lists Makefile
