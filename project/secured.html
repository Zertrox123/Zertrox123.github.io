Secured

2024 Structures de Données

Description du projet

Implémentation d'une bibliothèque C de table de hachage associative optimisée et sécurisée (B-CPE-110). Fonctionnalités principales : - Fonction de hachage sur mesure limitant les collisions et assurant une distribution uniforme - Gestion des collisions par chaînage avec listes chaînées - Opérations d'insertion (ht_insert), recherche (ht_search), suppression (ht_delete) et affichage (ht_dump) en complexité moyenne O(1) - Gestion rigoureuse de l'allocation dynamique et zéro fuite mémoire

Technologies utilisées

C Hash Table Data Structures Memory Management Algorithms
