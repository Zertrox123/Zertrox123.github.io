Description du projet

Implémentation d'une table de hachage associative optimisée et sécurisée en langage C. Fonctionnalités principales : - Fonction de hachage sur mesure limitant les collisions - Gestion des collisions par listes chaînées - Opérations d'insertion, recherche et suppression en complexité moyenne O(1)

Technologies utilisées

C Hash Table Data Structures Memory Management
