MyFTP

2026 Systèmes

📝 Description

Implémentation complète d'un serveur de transfert de fichiers (G-NWP-400) respectant la spécification RFC 959. Fonctionnalités principales : - Connexion de contrôle (port 21) et connexions de données dynamiques (modes PASV et PORT). - Implémentation des commandes standard : USER, PASS, CWD, CDUP, QUIT, DELE, PWD, PASV, PORT, HELP, NOOP, RETR, STOR, LIST. - Gestion des utilisateurs et isolation sécurisée des répertoires. Compétences clés : Protocoles RFC internet, sockets TCP doubles et transferts de données asynchrones.

Technologies

C RFC 959 TCP/IP Sockets Unix
