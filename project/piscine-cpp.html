Exercices d'apprentissage (Piscine C++ & Paradigmes)

2025-2026 Programmation Orientee Objet & C++

Description du projet

Serie d'exercices intensifs pour apprendre le C++ et les paradigmes de programmation (B-PDG-300 / Piscine C++). Ca couvre les fondamentaux de la POO (classes, heritage, polymorphisme, fonctions virtuelles), la surcharge d'operateurs, les templates, la STL (vector, map, list, iterateurs, algorithmes), la gestion d'exceptions et les smart pointers. La partie paradigmes introduit aussi la programmation fonctionnelle avec les lambdas et les fonctions d'ordre superieur.

Technologies utilisees

C++ OOP STL Templates RAII Makefile
