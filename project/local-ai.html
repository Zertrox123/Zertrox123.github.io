Local AI

2026 IA & LLM Local

Description du projet

Interface locale d'inférence et d'expérimentation avec des modèles de langage (LLMs) open source s'exécutant entièrement en local. Fonctionnalités principales : - Inférence locale accélérée sur CPU et GPU via Ollama et llama.cpp - Interface de discussion avec streaming des réponses et gestion du contexte - Pipeline RAG (Retrieval-Augmented Generation) pour interroger des documents locaux via base vectorielle

Technologies utilisées

Python LLM Ollama RAG Vector DB
