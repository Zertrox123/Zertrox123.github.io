Local AI

2026 IA & LLM Local

Description du projet

Plateforme locale d'inférence et d'orchestration de modèles de langage (LLMs) open-source fonctionnant 100% hors-ligne. Fonctionnalités principales : - Inférence locale accélérée sur GPU/CPU via llama.cpp et Ollama - Interface conversationnelle avec streaming et gestion de contexte - Système de RAG (Retrieval-Augmented Generation) sur documents locaux avec base vectorielle

Technologies utilisées

Python\n LLM\n Ollama\n RAG\n Vector DB
