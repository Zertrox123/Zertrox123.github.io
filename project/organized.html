2024 Structures de Donnees

Description du projet

Gestionnaire d'inventaire en C avec listes chainees (B-CPE-110). Le programme permet d'ajouter, supprimer, trier et afficher des elements dans un inventaire stocke en memoire via des listes doublement chainees. Tri multi-criteres par nom, type ou ID en ordre croissant ou decroissant. Bon exercice pour maitriser la manipulation de pointeurs et les structures de donnees dynamiques en C.

Technologies utilisées

C Listes Chaînées Algorythmes de tri Makefile
