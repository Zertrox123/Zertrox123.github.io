Organized

2024 Structures de Données & Tri

Description du projet

Gestionnaire d'inventaire matériel développé en langage C (B-CPE-110). Fonctionnalités principales : - Manipulation dynamique d'une base d'objets en mémoire via listes doublement chaînées - Implémentation d'algorithmes de tri multi-critères (par type, nom, ID, ordre croissant/décroissant) - Commandes d'ajout (add), suppression (del), tri (sort) et affichage (disp)

Technologies utilisées

C Linked Lists Sorting Algorithms Data Management
