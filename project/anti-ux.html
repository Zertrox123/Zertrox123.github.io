Anti-UX

2026 Frontend & Expérimentation

Description du projet

Expérimentation web interactive explorant les dark patterns et les mécaniques d'interfaces volontairement contre-intuitives. Fonctionnalités principales : - Boutons interactifs fuyants avec calcul de trajectoire selon la position du curseur - Formulaires piégés avec règles de validation contradictoires et comportements inattendus - Manipulations dynamiques du DOM et animations en JavaScript pur

Technologies utilisées

JavaScript HTML5 CSS3 DOM Manipulation UI/UX Experiment
