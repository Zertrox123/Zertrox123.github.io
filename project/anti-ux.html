2026 Frontend & Expérimentation

Description du projet

Application web interactive et humoristique explorant les pires motifs de design (dark patterns) et interfaces volontairement frustrantes. Fonctionnalités principales : - Boutons fuyants à l'approche de la souris avec détection trigonométrique - Formulaires trompeurs avec validations paradoxales et timers arbitraires - Design sonore déstabilisant et animations chaotiques en JavaScript pur

Technologies utilisées

JavaScript CSS Animations UI/UX Experiment DOM Manipulation
