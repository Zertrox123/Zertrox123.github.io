Tardis

2025 🎓 Scolaire

📝 Description

Ce projet consistait à développer une IA prédictive capable d’anticiper les retards de trains à partir d’un fichier Excel de données historiques. L’objectif était d’appliquer des méthodes de machine learning pour analyser des données réelles et fournir des prédictions fiables. Notre programme devait : extraire et nettoyer les données contenues dans un fichier Excel ; entraîner un modèle de prédiction à partir des caractéristiques disponibles (horaires, trajets, conditions, etc.) ; évaluer la précision des prédictions en comparant les résultats du modèle avec les données réelles ; générer des rapports ou visualisations permettant d’interpréter facilement les résultats. Les objectifs pédagogiques étant : approfondir la maîtrise du Python et des bibliothèques de data science (pandas, scikit-learn) ; apprendre à manipuler et prétraiter des données brutes issues d’Excel ; comprendre les principes fondamentaux du machine learning supervisé ; développer des compétences en évaluation de modèles et en communication de résultats à travers des visualisations.

🛠️ Technologies
