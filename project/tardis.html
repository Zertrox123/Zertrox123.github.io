Tardis AI

2026 Machine Learning & Data

Description du projet

Modèle d'apprentissage automatique prédictif analysant les retards ferroviaires à partir de données historiques et météorologiques. Fonctionnalités principales : - Nettoyage, normalisation et ingénierie de variables (Feature Engineering) sur de larges volumes de données - Entraînement de modèles de régression et forêts aléatoires pour anticiper les temps de parcours - Évaluation des performances du modèle (RMSE, R2) et visualisation des corrélations

Technologies utilisées

Python Machine Learning Data Science Pandas Scikit-Learn
