Tardis AI

2026 Machine Learning & Data

Description du projet

Modèle de machine learning supervisé développé pour analyser et prédire les retards ferroviaires à partir de données historiques de circulation et de conditions météorologiques. Fonctionnalités principales : - Nettoyage, normalisation et sélection de variables (feature engineering) avec Pandas et NumPy - Entraînement et comparaison de modèles de régression (Random Forest, régression linéaire, Gradient Boosting) via Scikit-Learn - Évaluation des performances prédictives (RMSE, MAE, score R²) et analyse des corrélations

Technologies utilisées

Python Pandas NumPy Scikit-Learn Machine Learning
