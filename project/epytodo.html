Description du projet

API REST backend complète pour une application de gestion de tâches (TODO list) avec authentification sécurisée. Fonctionnalités principales : - Endpoints RESTful pour la gestion des utilisateurs et des tâches (CRUD complet) - Authentification par tokens JWT et hachage sécurisé des mots de passe (bcrypt) - Persistance des données dans une base relationnelle MySQL avec requêtes préparées

Technologies utilisées

Node.js Express MySQL REST API JWT Backend
