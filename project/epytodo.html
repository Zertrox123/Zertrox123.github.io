Description du projet

API REST backend complète pour une application de gestion de tâches (TODO list) avec authentification sécurisée et base de données relationnelle. Fonctionnalités principales : - Endpoints RESTful complets pour les opérations CRUD sur les utilisateurs et les listes de tâches. - Authentification sécurisée par jetons JWT (JSON Web Tokens) et hachage des mots de passe avec bcrypt. - Intégration MySQL avec requêtes préparées pour la persistance des données et la protection contre les injections SQL. - Architecture logicielle modulaire découpée en routes, middlewares d'authentification et contrôleurs.

Technologies utilisées

Node.js Express MySQL JWT bcrypt API REST Backend
