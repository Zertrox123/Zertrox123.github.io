EpyTodo

2025 🛠️ Outils & Web

📝 Description

Application web backend (B-WEB-200) structurée autour d'une architecture MVC pour la gestion d'utilisateurs et de tâches. Fonctionnalités principales : - Authentification sécurisée par tokens JWT et hashage de mots de passe (bcrypt). - Endpoints RESTful complets pour les opérations CRUD sur les utilisateurs et tâches. - Connexion et requêtes optimisées vers une base relationnelle MySQL.

🛠️ Technologies

Node.js Express MySQL JWT REST API
