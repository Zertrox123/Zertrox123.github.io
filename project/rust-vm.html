Rust VM

2026 Machine Virtuelle & Rust

Description du projet

Interpréteur de bytecode et machine virtuelle basée sur registres développée en Rust. Fonctionnalités principales : - Définition d'un jeu d'instructions assembleur personnalisé (arithmétique, sauts conditionnels, pile, mémoire) - Interpréteur de bytecode optimisé avec sécurité mémoire garantie sans garbage collector - Désassembleur intégré et débogueur pas-à-pas avec inspection des registres et de la pile

Technologies utilisées

Rust Virtual Machine Bytecode Interpreter Low-Level
