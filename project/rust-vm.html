Rust VM

2026 Machine Virtuelle & Rust

Description du projet

Machine virtuelle à pile et interpréteur de bytecode personnalisé développés en Rust avec des mécanismes de sécurité et d'anti-analyse. Fonctionnalités principales : - Jeu d'instructions sur mesure (opérations arithmétiques, pile, sauts conditionnels, appels de fonctions) - Modèle mémoire avec émulation de RAM, gestion de la pile d'exécution et table de fonctions dynamique - Mécanismes de protection : effacement sécurisé de la mémoire (zeroize), détection de débogage temporel et obfuscation de chaînes

Technologies utilisées

Rust Virtual Machine Bytecode Low-Level Security
