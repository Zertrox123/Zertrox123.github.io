Sokoban

2024 Graphisme 2D & Terminal

Description du projet

Jeu de reflexion Sokoban en C avec ncurses (B-PSU-100). Le joueur pousse des caisses sur des emplacements cibles dans un labyrinthe. Parsing de maps depuis des fichiers texte, gestion des deplacements et des collisions, detection automatique de victoire quand toutes les caisses sont placees. Interface en terminal avec ncurses pour gerer les touches directionnelles et l'affichage en temps reel.

Technologies utilisees

C ncurses Makefile
