Sokoban

2024 Terminal & ncurses

Description du projet

Jeu de réflexion Sokoban développé en C avec la bibliothèque ncurses (B-PSU-100). Fonctionnalités principales : - Parsing et validation rigoureuse de maps personnalisées depuis un fichier - Gestion des déplacements du joueur, poussée de caisses et détection d'obstacles - Détection automatique de condition de victoire (toutes les caisses sur les emplacements) et de blocage / défaite (caisses bloquées dans les coins) - Redimensionnement dynamique de la fenêtre terminal avec message d'alerte

Technologies utilisées

C ncurses Algorithms Parsing Unix
