Youtube Game

2020 💼 Personnel

📝 Description

Ce projet consistait à développer en Python un bot Discord personnel nommé "Youtube Game". L’objectif était d’intégrer un système de jeu interactif directement dans Discord, tout en manipulant une base de données pour stocker et gérer les informations des utilisateurs. Notre programme devait : interagir avec les utilisateurs via des commandes Discord ; proposer un système de jeu lié à YouTube et à la progression des joueurs ; enregistrer et gérer les données des utilisateurs dans une base MySQL ; assurer la persistance des scores, statistiques et classements ; gérer la communication entre le bot et la base de données de manière sécurisée et optimisée. Les objectifs pédagogiques étant : renforcer la maîtrise du langage Python ; apprendre à concevoir et déployer un bot Discord ; manipuler une base de données relationnelle MySQL pour stocker et organiser des données persistantes ; développer des compétences en gestion d’événements asynchrones et en intégration d’API externes.

🛠️ Technologies

Python MySQL
