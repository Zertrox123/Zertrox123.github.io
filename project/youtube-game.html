2025 Bots & Jeux

Description du projet

Bot Discord interactif intégrant un système de jeu RPG et d'économie virtuelle pour animer des communautés. Fonctionnalités principales : - Commandes et interactions asynchrones gérées via l'API Discord (discord.py) - Système de progression, gestion d'inventaire, économie virtuelle et combats au tour par tour - Base de données MySQL pour la persistance des profils et des statistiques des joueurs

Technologies utilisées

Python discord.py MySQL AsyncIO Discord API
