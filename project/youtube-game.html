Description du projet

Bot Discord interactif intégrant un système complet de jeu RPG communautaire. Fonctionnalités principales : - Système économique virtuel, inventaire d'objets, quêtes et combats au tour par tour - Intégration de commandes slash Discord et gestion d'événements asynchrones - Base de données MySQL pour la sauvegarde persistante des profils joueurs

Technologies utilisées

Python\n discord.py\n MySQL\n AsyncIO\n Bot\n RPG
