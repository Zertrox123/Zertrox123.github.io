Cinedle

2025 Web & Jeux

Description du projet

Jeu web interactif quotidien de devinettes cinématographiques inspiré du principe de Wordle. Fonctionnalités principales : - Algorithme de comparaison par indices progressifs (année, genre, réalisateur, casting, box-office) - Intégration de l'API TMDB pour une base de données de milliers de films - Système de statistiques de victoires et partage de scores

Technologies utilisées

JavaScript HTML5 CSS3 REST API TMDB Game
