Cinedle

2025 Web & Jeux

Description du projet

Jeu web quotidien de devinettes cinématographiques inspiré du concept de Wordle appliqué aux films. Fonctionnalités principales : - Système d'indices progressifs comparant chaque proposition au film mystère (année, genres, réalisateur, casting, pays) - Intégration de l'API TMDB pour l'autocomplétion des titres et la récupération dynamique des métadonnées - Sauvegarde locale de la partie journalière et calcul des statistiques de victoires

Technologies utilisées

JavaScript HTML5 CSS3 REST API TMDB
