Navy

2024 Systemes Unix

Description du projet

Jeu de bataille navale en C ou deux processus communiquent par signaux Unix (B-PSU-100). Chaque joueur lance son processus avec un fichier de placement de bateaux. La communication se fait uniquement par SIGUSR1 et SIGUSR2, ce qui oblige a encoder les coordonnees de tir bit par bit via les signaux. Gestion du tour par tour, detection des touches/coules et affichage des grilles dans le terminal.

Technologies utilisees

C Unix Signals IPC Makefile
