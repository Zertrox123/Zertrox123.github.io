Setting Up (BSQ)

2024 Algorithmique & Optimisation

Description du projet

Algorithme d'optimisation en C permettant de localiser le plus grand carré possible dans un plateau 2D parsemé d'obstacles (B-CPE-110). Fonctionnalités principales : - Programmation dynamique en complexité O(N*M) capable de traiter des grilles de plusieurs millions de cases en une fraction de seconde - Lecture binaire optimisée par buffers de lecture sans surcharge mémoire - Générateur et validateur de maps avec détection des formats invalides

Technologies utilisées

C Dynamic Programming Optimization Algorithms Unix
