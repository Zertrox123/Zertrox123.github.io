MyTeams

2026 Systèmes & Réseau

Description du projet

Développement d'un serveur et client de communication collaborative multi-utilisateurs. Fonctionnalités principales : - Serveur asynchrone non-bloquant gérant de multiples connexions simultanées avec select/poll - Architecture : Équipes (Teams), Canaux (Channels), Fils de discussion (Threads) et Messages privés (DMs) - Protocole réseau binaire sur mesure et persistance des données sur disque

Technologies utilisées

C TCP/IP Sockets select I/O Multiplexing Unix
