MyTeams

2026 ⚡ Systèmes

📝 Description

Développement d'un serveur et client de communication collaborative (G-NWP-400). Fonctionnalités principales : - Serveur asynchrone non-bloquant gérant de multiples connexions simultanées avec select/poll. - Architecture : Équipes (Teams), Canaux (Channels), Fils de discussion (Threads) et Messages privés (DMs). - Protocole réseau binaire sur mesure et persistance des données sur disque. Compétences clés : Programmation réseau bas-niveau en C, sockets TCP, sérialisation binaire et gestion d'état serveur.

🛠️ Technologies

C TCP/IP Sockets select I/O Multiplexing Unix
