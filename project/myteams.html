MyTeams

2026 Systèmes & Réseau

Description du projet

Plateforme de messagerie instantanée collaborative multi-utilisateurs (style Slack / Microsoft Teams) basée sur une architecture client-serveur TCP. Architecture du système : - Serveur en Rust : Gestion réseau asynchrone non-bloquante pour accueillir plusieurs clients en simultané, structuration hiérarchique des données (équipes, canaux, threads, commentaires, messages privés) et persistance sur disque. - Client CLI en C++20 : Interface interactive en ligne de commande permettant de s'authentifier, créer et rejoindre des canaux, échanger des messages en direct et recevoir les notifications d'événements.

Technologies utilisées

Rust C++20 TCP/IP Sockets CLI Protocole Réseau Sérialisation
