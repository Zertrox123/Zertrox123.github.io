Corewar

2025 Systèmes & Machine Virtuelle

Description du projet

Projet d'émulation bas niveau simulant une arène mémoire partagée où s'affrontent des programmes champions écrits en assembleur. Composants du projet : - Assembleur (asm) : Analyse du code source assembleur (.s) et conversion en bytecode binaire (.cor). - Machine Virtuelle (corewar) : Simulation d'une arène mémoire circulaire de 6 Ko, exécution des instructions des champions tour par tour avec gestion des cycles et détection du dernier survivant.

Technologies utilisées

C Assembleur Bytecode Machine Virtuelle Gestion Mémoire Unix
