Description du projet

Système d'agents conversationnels autonomes dotés de mémoire contextuelle et de profils de personnalité personnalisables. Fonctionnalités principales : - Traitement du langage naturel (NLP) et adaptation dynamique du ton selon le profil de persona - Gestion de mémoire à court et long terme pour un suivi conversationnel cohérent - Interface web interactive et API d'intégration

Technologies utilisées
