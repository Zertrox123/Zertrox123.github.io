Geometry Dash Recorder

2025 💼 Personnel

📝 Description

Ce projet consistait à développer en Python un enregistreur automatique pour Geometry Dash. L’objectif était d’automatiser la capture des runs (vidéo et/ou inputs) afin d’analyser les parties, de créer des replays ou d’archiver des performances sans intervention manuelle. Notre programme devait : détecter automatiquement le début et la fin d’un run dans le jeu (via reconnaissance d’écran ou écoute d’événements) ; enregistrer la vidéo du gameplay en temps réel (ex. via ffmpeg, mss ou pyautogui) et/ou logger les inputs clavier/souris avec timestamps ; sauvegarder les fichiers de manière structurée (date, niveau, score) ; proposer une option de replay/relecture en rejouant les inputs ou en ouvrant la vidéo ; gérer les performances pour minimiser l’impact sur le jeu (encodage en arrière-plan, framerate contrôlé). Les objectifs pédagogiques étant : approfondir la maîtrise du langage Python ; apprendre l’automatisation et la capture d’écran/vidéo (intégration de ffmpeg/bibliothèques natives) ; manipuler la capture d’inputs et la sérialisation de données temporelles ; découvrir des techniques basiques de traitement d’images pour la détection d’événements dans le jeu ; développer des compétences en optimisation et en gestion de fichiers multimédias.
