Geometry Dash Recorder

2025 💼 Personnel

📝 Description

Outil d'automatisation en Python pour la capture de gameplay et la journalisation d'événements. Fonctionnalités principales : - Détection automatique du début et fin de run par analyse d'images en direct. - Enregistrement vidéo en tâche de fond avec accélération FFmpeg. - Logger d'inputs clavier/souris avec timestamps précis pour relecture et analyses.

🛠️ Technologies

Python OpenCV FFmpeg Automation
