2025 Graphisme 2D & Simulation

Description du projet

Simulation graphique 2D de contrôle aérien avec détection de collisions en C CSFML. Fonctionnalités principales : - Déplacement simultané de centaines d'avions avec calcul vectoriel de trajectoires - Tours de contrôle avec zones de sécurité circulaires - Optimisation des tests de collision par quadtree spatial

Technologies utilisées

C CSFML 2D Graphics Collision Detection Quadtree
