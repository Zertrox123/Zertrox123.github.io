MyRadar

2025 Graphisme 2D

Description du projet

Simulateur de trafic aerien en 2D avec la CSFML (B-MUL-100). Le programme affiche une carte avec des avions qui se deplacent en temps reel vers leur destination. Il faut gerer les zones d'exclusion aerienne (les avions doivent les contourner ou s'ils y entrent ils disparaissent) et detecter les collisions entre avions. Gestion d'events clavier pour afficher/cacher les hitboxes et les zones.

Technologies utilisees

C CSFML 2D Rendering Makefile
