Description du projet

Outil d'analyse statique et de nettoyage automatique de code source pour respecter les standards de qualité. Fonctionnalités principales : - Analyse syntaxique et détection de mauvaises pratiques, fonctions trop longues et variables inutilisées - Formatage et refactoring automatique respectant les normes de codage - Rapport d'analyse détaillé avec suggestions d'optimisation

Technologies utilisées

Python AST Static Analysis Code Quality Linter
