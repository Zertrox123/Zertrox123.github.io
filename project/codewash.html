2026 Génie Logiciel & Frontend

Description du projet

Projet de génie logiciel, refactorisation et optimisation d'une application frontend et desktop (module G-ING-400). Fonctionnalités principales : - Application interactive développée avec React 19, Vite et stylisée avec Tailwind CSS. - Packaging desktop multi-plateforme avec Electron et build d'exécutables portables via electron-builder. - Refactoring complet d'une base de code existante : modularisation des composants, élimination du code mort et optimisation des performances de rendu. - Automatisation des tests unitaires et de non-régression avec Vitest (couverture de code V8) et contrôle qualité via ESLint.

Technologies utilisées

React 19 Vite Electron Tailwind CSS JavaScript Vitest
