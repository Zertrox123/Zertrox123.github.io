Cuddle & Chocolatine

2026 CI/CD & Qualité Logicielle

Description du projet

Conception et automatisation d'un pipeline d'intégration continue (CI/CD) complet avec GitHub Actions pour garantir la conformité et la qualité du code. Structure du pipeline (jobs séquentiels) : - Vérification de la norme de codage : Exécution de l'analyseur de style officiel sous conteneur Docker et génération d'annotations d'erreurs directement sur les commits et pull requests. - Contrôle de compilation : Compilation du projet avec Makefile sous conteneur Docker (Epitest), validation des règles clean et détection des exécutables requis avec timeout. - Exécution des tests : Lancement automatique des suites de tests unitaires (make tests_run) avec gestion des temps limites. - Déploiement miroir : Synchronisation automatique vers le dépôt miroir distant via clé SSH sécurisée.

Technologies utilisées

GitHub Actions CI/CD Docker Bash Makefile Automatisation Qualité Logicielle
