Description du projet

Voiture autonome en C qui doit rouler le plus longtemps possible sur un circuit sans toucher les murs (B-AIA-100). Le programme recoit les donnees des capteurs de distance (lidars) via stdin et renvoie les commandes de direction et de vitesse via stdout. L'algo doit analyser les distances aux murs pour adapter la trajectoire en temps reel. Le challenge c'est de trouver le bon equilibre entre vitesse et precision pour pas se crasher dans les virages serres.

Technologies utilisees

C Autonomous Driving Lidar Processing Makefile
