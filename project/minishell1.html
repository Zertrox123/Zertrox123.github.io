Minishell 1

2024 Systemes Unix

Description du projet

Premier shell Unix en C (B-PSU-100). Le programme lit les commandes utilisateur, les parse et les execute via fork/execve. Gestion de la variable PATH pour trouver les executables, et implementation des builtins : cd, setenv, unsetenv, env et exit. C'est la base avant minishell2 : pas de pipes ni de redirections, mais ca pose les fondations de la gestion de processus Unix.

Technologies utilisees

C fork / execve Unix Makefile
