Popeye & RobotFactory

2025 DevOps & Conteneurisation

Description du projet

Introduction a Docker et Docker Compose (B-DOP-200). Popeye c'est le premier projet Docker : ecrire des Dockerfiles pour conteneuriser une appli web multi-services (frontend, backend, base de donnees) et les orchestrer avec un docker-compose.yml. Gestion des reseaux, volumes et variables d'environnement. RobotFactory va plus loin avec des Dockerfiles multi-stage optimises pour reduire la taille des images et la separation des environnements de build et de production.

Technologies utilisees

Docker Docker Compose DevOps Microservices
