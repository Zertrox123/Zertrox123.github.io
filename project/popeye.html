Popeye & RobotFactory

2025 DevOps & Conteneurisation

Description du projet

Projets d'infrastructure et de déploiement conteneurisé d'applications distribuées. Fonctionnalités principales : - Création et optimisation de Dockerfiles multi-stage pour réduire l'empreinte des images - Orchestration de microservices interconnectés avec Docker Compose (réseaux isolés, volumes de données persistants) - Déploiement d'applications web multi-tiers (Frontend, Backend API, Base de données PostgreSQL/Redis)

Technologies utilisées

Docker\n Docker Compose\n DevOps\n Microservices\n CI/CD
