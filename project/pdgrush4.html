PDG Rush 4

2026 Paradigmes de Programmation

Description du projet

Conception d'un paradigme orienté objet dynamique complet implémenté en langage C pur (B-PDG-300). Fonctionnalités principales : - Système de classes, instanciation, héritage simple et polymorphisme en C - Table virtuelle de méthodes (vtable) avec dispatch dynamique - Implémentation d'itérateurs, conteneurs et surcharge d'opérateurs arithmétiques/comparatifs

Technologies utilisées

C\n Object-Oriented C\n vtable\n Polymorphism\n Memory Architecture
