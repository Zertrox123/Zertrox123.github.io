CVRIE (Computer Vision)

2026 🤖 IA & Data

📝 Description

Projet d'intelligence artificielle (G-AIA-400) spécialisé dans le traitement d'images et la reconnaissance de formes. Fonctionnalités principales : - Traitement d'images numériques (filtrage, détection de contours, seuillage adaptatif) avec OpenCV. - Extraction automatique de zones d'intérêt et classification d'éléments visuels. - Pipelines de prétraitement pour optimiser la précision des modèles de détection.

🛠️ Technologies

Python OpenCV Computer Vision NumPy
