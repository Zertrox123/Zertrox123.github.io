CVRIE (Machine Learning & Vision)

2026 Intelligence Artificielle

Description du projet

Projet d'intelligence artificielle appliquée combinant classification d'images médicales et analyse de données par clustering. Volets du projet : - Apprentissage supervisé : Classification d'images médicales (radiographies thoraciques PneumoniaMNIST). Entraînement et comparaison de modèles avec scikit-learn (Régression Logistique, Random Forest, SVM linéaire), normalisation des pixels et optimisation du seuil de décision sur la validation pour maximiser la balanced accuracy. - Apprentissage non supervisé : Analyse exploratoire et regroupement automatique de données par clustering K-Means.

Technologies utilisées

Python scikit-learn NumPy pandas Machine Learning Computer Vision
