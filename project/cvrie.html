CVRIE (Machine Learning & Vision)

2026 Intelligence Artificielle

Description du projet

Projet d'intelligence artificielle appliquée combinant classification d'images médicales et analyse textuelle non supervisée. Volets du projet : - Apprentissage supervisé : Classification d'images médicales (radiographies thoraciques PneumoniaMNIST). Comparaison de modèles avec scikit-learn (Régression Logistique, Random Forest, SVM linéaire calibré), normalisation des pixels, gestion du déséquilibre de classes et recherche du seuil de décision optimal sur le split de validation pour maximiser la balanced accuracy sans fuite de données. - Apprentissage non supervisé : Pipeline de traitement du langage naturel (NLP) sur un corpus de témoignages, vectorisation par TF-IDF et regroupement sémantique par clustering K-Means.

Technologies utilisées

Python scikit-learn NumPy pandas Matplotlib Machine Learning NLP
