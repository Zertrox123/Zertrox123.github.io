Portfolio Web en Rust

2026 Web & Backend Rust

Description du projet

Application web de portfolio conçue avec un backend ultra-rapide et sécurisé en langage Rust. Fonctionnalités principales : - Serveur HTTP asynchrone propulsé par le framework Rocket - Rendu dynamique de templates côté serveur avec Tera - Architecture modulaire, isolation des données sensibles et sécurité maximale

Technologies utilisées

Rust\n Rocket\n Tera\n HTML5\n CSS3\n Web Server
