📝 Description

Dans le cadre de mon apprentissage de Rust, j’ai développé un portfolio interactif permettant de présenter mes projets et mes compétences. Contrairement à une simple page statique, l’objectif était d’utiliser Rust pour gérer la structure et la logique côté serveur, tout en proposant une interface web moderne. Les caractéristiques principales étant: Développer avec Rust et un framework web (Rocket); Mise en place d’un système de templates dynamiques pour l’affichage des projets; Gestion de données (projets, descriptions, liens GitHub) à partir de fichiers JSON; Interface responsive avec une mise en valeur claire des compétences. Les Objectifs du projet: Mettre en pratique les bases de Rust dans un projet concret; Découvrir la programmation web côté serveur en Rust; Créer un outil personnel réutilisable et extensible pour présenter mes projets.
