2026 Web & Backend Rust

Description du projet

Site portfolio personnel développé avec un backend en Rust (Rocket et Tera) et une interface web responsive. Fonctionnalités principales : - Serveur HTTP en Rust avec rendu de templates Tera et routing dynamique - Espace d'administration pour gérer les projets - Interface responsive avec système de filtres par catégorie et par langage

Technologies utilisées

Rust Rocket Tera HTML5 CSS3 JavaScript
