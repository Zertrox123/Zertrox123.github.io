Amazed

2025 Algorithmique

Description du projet

Algorithme de recherche du plus court chemin dans un labyrinthe (B-CPE-200). Le programme lit une carte contenant des salles et des tunnels entre elles, puis calcule le nombre minimum de tours pour faire passer un groupe de robots du point d'entree au point de sortie. La difficulte principale est de gerer les flux multiples : plusieurs robots doivent avancer en parallele sans se bloquer dans les salles intermediaires.

Technologies utilisees

C Pathfinding Graph Theory Makefile
