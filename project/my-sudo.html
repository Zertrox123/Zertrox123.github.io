my_sudo

2025 Systemes Unix

Description du projet

Recreation de la commande sudo en C (B-PSU-200). Le programme gere l'authentification par mot de passe, l'execution de commandes avec changement d'utilisateur et de groupe (setuid/setgid), la verification des permissions via un fichier de config type sudoers, et le logging des actions. Il faut gerer les options -u (utilisateur cible), -g (groupe) et parser correctement le fichier de configuration pour verifier les droits.

Technologies utilisees

C Unix Syscalls setuid / setgid Authentication Makefile
