My Sudo

2025 🎓 Scolaire

📝 Description

Ce projet consistait à reprogrammer en langage C la commande sudo de Linux. L’objectif était de comprendre le fonctionnement des systèmes d’authentification sous Unix et les mécanismes permettant d’exécuter des commandes avec des privilèges élevés de manière sécurisée. Notre programme devait : demander le mot de passe de l’utilisateur avant l’exécution ; vérifier les droits en consultant un fichier de configuration (type /etc/sudoers simplifié) ; exécuter la commande demandée avec les privilèges administrateur uniquement si l’utilisateur était autorisé ; gérer les erreurs comme un mot de passe incorrect, une absence de droits ou une commande invalide. Les objectifs pédagogiques étant : approfondir la maîtrise du langage C ; manipuler la gestion des droits et privilèges utilisateurs sous Linux ; comprendre le fonctionnement bas niveau de l’authentification et de l’exécution sécurisée ; développer des compétences en gestion des erreurs et sécurité dans un programme système.
