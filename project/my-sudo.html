My Sudo

2025 ⚡ Systèmes

📝 Description

Reprogrammation en langage C du mécanisme d'élévation de privilèges sous Unix. Fonctionnalités principales : - Authentification utilisateur par mot de passe. - Vérification des droits dans les fichiers de configuration sudoers. - Exécution des commandes avec privilèges root temporaires et gestion d'erreurs sécurisée.

🛠️ Technologies

C Unix Security Authentication
