Exercices d'apprentissage (Piscine C)

2024 Fondamentaux & C

Description du projet

Mois d'immersion intensive en C pour apprendre les bases de la programmation systeme (B-CPE-100 / Piscine C). Chaque jour un nouveau theme avec des exercices de difficulte croissante : manipulation de chaines, pointeurs, allocation dynamique avec malloc/free, listes chainees, lecture de fichiers avec les syscalls Unix (open/read/write/close), Makefiles, et pointeurs de fonctions. Les rushs du week-end c'est des epreuves en equipe avec un timing serre, ca apprend a coder vite et a se repartir le travail.

Technologies utilisees

C Pointers Memory Management Data Structures Makefile Unix
